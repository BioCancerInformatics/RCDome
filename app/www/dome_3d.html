3D RCDome requires a WebGL-capable browser

Your browser did not create a WebGL context, so the 3D sphere cannot render.

  • Hardware acceleration disabled — enable it in your browser settings (or it may be off by an enterprise/group policy).
  • GPU blocklisted — the browser disabled WebGL for your GPU/driver; update the graphics driver or try Chrome/Edge.
  • VM / remote desktop — RDP/Citrix/cloud VMs often give the browser no GPU; open the app on a local machine with a GPU.

Use the Network module for the 2D gene–entity view in the meantime.
